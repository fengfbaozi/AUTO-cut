# 自动视频切片工具（AutoCut）

一个模仿 **LosslessCut** 操作逻辑的本地视频剪辑工具：通过分析**画面运动**，自动识别并删除**长时间没有动作**的废镜头，保留有内容的关键片段，人工微调后一键导出精简成片。

适用于操作演示、活动记录、Vlog 等以画面动作为主的视频。全程本地离线处理，不上传视频。基于 **PySide6**（界面）+ **OpenCV / NumPy**（运动检测）+ **FFmpeg**（切片导出）。

> **给完全不会代码的你**：这个程序装好之后，用起来和普通软件一样简单——
> 双击 `启动工具.bat` 就会弹出窗口，全程不用写任何代码。
> 第一次使用只需要按下面的「安装」步骤，让技术人员帮你装好 3 样东西（Python、FFmpeg、依赖包），以后就能一直用了。

---

## 功能特性

- **自动分析废镜头**：基于画面运动（帧差法）判定「有没有动作」，不受背景音乐 / 环境噪音影响
- **LosslessCut 式时间轴**：保留段为柔和绿色、删除段为暗灰弱化显示，可拖拽切点、滚轮缩放、迷你概览图
- **多视频目录**：一次导入多个视频，点击切换时播放器 / 时间轴 / 片段目录整体切换，互不干扰
- **「浏览镜头」模式**：删除段直接消失，保留段无缝拼接成一条「成片」，从零开始连续播放预览
- **两段式精裁**：「自动分析」先粗裁 → 「聚焦镜头」放大单个镜头精调切点（快捷键 I / O）
- **右侧片段目录**：勾选「保留」切换保留/删除，缩略图 + 独立编号（镜头 N / 废 N）
- **锁定防误触**：开启后已删除的废镜头不可点击/拖动，放心点镜头号
- **防呆设计**：会话自动保存（崩溃后启动询问恢复）、窗口位置记忆、原视频被移动/删除自动跳过
- **导出确认**：导出前弹窗核对视频名 / 保留镜头数 / 总时长 / 命名示例 / 输出目录 / 覆盖警告

## 快捷键（模仿 LosslessCut）

| 按键 | 功能 |
|------|------|
| `空格` | 播放 / 暂停 |
| `I` / `O` | 设起点 / 设终点（精调选中镜头切点） |
| `Delete` | 切换选中镜头 保留/删除 |
| `←` / `→` | 上一帧 / 下一帧 |

## 命名规则

导出支持「前缀 + 自动序号（1 位 / 2 位 / 3 位）+ 后缀」的自定义命名，例如 `演示_01段.mp4`。

## 安装与运行

> 只需要装一次。装好之后，以后每次直接用就行。

### 环境要求

- **Windows 系统**
- **Python 3.10+**（[官网下载](https://www.python.org/downloads/)）
- **FFmpeg**（视频处理工具，[下载教程](https://www.bilibili.com/search?keyword=ffmpeg%20%E5%AE%89%E8%A3%85%20windows)）

### 第 1 步：确认 Python 装好

在命令行输入下面命令，能显示版本号（如 `Python 3.12.x`）就说明装好了：

```bash
python --version
```

### 第 2 步：确认 FFmpeg 装好

在命令行输入下面命令，能显示版本号（如 `ffmpeg version ...`）就说明装好了：

```bash
ffmpeg -version
```

> 程序会自动从 PATH 和常见安装目录查找 ffmpeg，不需要额外配置。

### 第 3 步：安装依赖包

在项目目录里打开命令行，运行：

```bash
pip install -r requirements.txt
```

### 启动程序

- **方式一（推荐）**：直接双击项目里的 `启动工具.bat`。
- **方式二**：在项目目录打开命令行，运行 `python main.py`。

### 使用流程（三步）

1. 左上角「📂 导入视频」（可一次多选）
2. 点「🔍 自动分析」→ 删除段自动标灰；在时间轴 / 右侧目录人工微调（拖切点、勾保留、I/O 精裁）
3. 右下角「📤 导出」→ 确认后导出（每个保留镜头独立文件，或合并为一个视频）

## 技术细节

### 1. 核心检测信号：画面运动（帧差法）

很多视频全程有背景音乐 / 环境噪音（操作演示、活动录像、Vlog 等），**音频静音检测不可靠**，因此核心判定只看画面：

```
相邻两帧像素差异越大 → 动作越多
操作 / 演示 / 运动等有内容的画面 → 画面变化大 → 保留
镜头静止 / 空镜 / 等待间隙          → 画面几乎不变 → 删除
```

### 2. 运动分析引擎（`core/motion_analyzer.py`）

直接逐帧解码 4K 视频做帧差很慢，采用了三重提速：

- **只解码关键帧**：`ffmpeg -skip_frame nokey`，跳过绝大部分 P/B 帧
- **分块并行**：按 90 秒一块，最多 4 路同时解码（`ThreadPoolExecutor`），充分利用多核
- **深度降采样**：`scale=192:h, fps=2, format=gray`，输出 rawvideo 灰图，每帧仅 192×108 字节

得到灰度帧后用 NumPy 做帧差：`absdiff → 阈值 25 二值化 → 变化像素占比 = 运动分(0~1)`，再按秒聚合输出每秒运动分曲线。

> 实测：11 分钟 4K 视频从 ~71 秒降到 ~10 秒完成分析。

### 3. 片段决策器（`core/segment_decider.py`）

把每秒运动分曲线切成「保留段 / 删除段」：

1. **二值化**：运动分 ≥ 阈值 → 有动作（`Config.strength=50` 时阈值 = 0.03）
2. **中值平滑**（窗口 3 秒）：去掉单秒抖动
3. **切段**：连续同类帧合并为一段
4. **过滤短片段**：保留段 < 1s → 转删除；删除段 < 1s → 转保留（去碎片）
5. **加前后余量**（0.3s）：保留段前后各留过渡，避免切得太干

### 4. 导出（`core/exporter.py`）

| 模式 | 原理 | 特点 |
|------|------|------|
| 快速无损 | `ffmpeg -c copy` 流复制 | 快、画质零损失；切点需对齐关键帧 |
| 精确 | `libx264 crf 18 + aac 192k` 重编码 | 切点精确；会重新编码，画质轻微损失 |

每个保留镜头独立导出，文件名按「前缀_序号_后缀」自动编号；也可合并为一个视频。

### 5. 「浏览镜头」模式：虚拟时间轴（`ui/timeline.py`）

进入浏览模式后，时间轴切换到**紧凑视图**：已删除的片段从时间条上消失，保留段首尾拼接成一条「成片」，播放头回到虚拟起点并从零连续播放。

- 通过 `orig_to_virt()` / `virt_to_orig()` 完成**原始时间 ⇄ 虚拟时间**的双向映射
- 播放进入删除段时自动 seek 跳到下一个保留镜头（带防重入保护，避免 seek 反馈循环）
- 退出浏览模式后自动恢复完整时间轴，播放头转回原视频对应位置

### 6. 会话持久化（`core/session.py`）

分析结果和手动调整**实时**写入 `~/.autocut_session.json`（原子写入，防写坏）。
程序崩溃 / 误关后下次启动会弹窗询问是否恢复；原视频被移动 / 删除时自动跳过对应视频，不报错。
窗口位置和大小通过 `QSettings` 记忆。

## 常见问题（FAQ）

**双击「启动工具.bat」一闪就没了？**
一般是依赖没装好或环境问题。先确认：① `python --version` 能输出版本号；② `pip install -r requirements.txt` 执行过且没报错。然后把窗口里的报错内容截图发给我排查。

**提示「找不到 FFmpeg」/ 分析、导出失败？**
先确认命令行里 `ffmpeg -version` 能输出版本号。如果没安装，按上文「第 2 步」装好并重启命令行 / 重新双击启动脚本即可。

**视频能导入但播放器黑屏？**
试试用 `python test_player.py 视频路径` 验证本机能否播放该视频。个别编码格式（如某些 4K HEVC）系统解码器不支持，可先用格式工厂等工具转成 mp4（H.264）再导入。

**点「自动分析」很慢？**
4K 长视频分析需要解码画面，11 分钟视频约 10 秒完成属正常水平；时间长短取决于视频时长和电脑性能。

**分析结果不合心意？**
分析只是「自动粗裁」，请务必在时间轴 / 右侧目录人工微调：拖动绿色段的边缘改切点、勾掉「保留」可切换保留/删除、用「聚焦镜头」放大精调，最后再导出。

**导出的视频画质变差了吗？**
默认「快速无损」模式是流复制（`-c copy`），画质零损失；只有你主动选择「精确」模式才会重编码。
